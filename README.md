# Mémoire vive

Le musée de HappyKing : quarante-cinq ans de jeux vidéo, des consoles Pong et de l'Atari 800 XL jusqu'à la Switch 2, racontés salle par salle.

**Visiter : https://happyking.github.io/memoire-vive**

Cinq salles, cinq chapitres de ma vie de joueur, de l'enfance et des salles d'arcade jusqu'aux parties avec mes enfants. Chaque jeu est rangé à l'année où je l'ai découvert, avec, pour les pièces qui ont compté, un cartel qui raconte leur histoire. Des parcours thématiques (séries, studios, lieux, moments) traversent les salles.

## Contenu

- `index.html` : le musée (une page statique, sans dépendance)
- `data.json` : la collection, un jeu par machine sur laquelle il a été joué
- `tags.json` : les parcours thématiques et leur présentation
- `machines.json` : les notes sur les machines

Les données sont tirées de mon archive personnelle et régénérées à chaque mise à jour.
